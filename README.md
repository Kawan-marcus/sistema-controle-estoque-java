# Sistema de Controle de Estoque

Projeto desenvolvido em Java para gerenciamento de produtos.

## Funcionalidades

- Cadastro de produtos
- Listagem de produtos
- Busca de produtos
- Remoção de produtos
- Controle de estoque
- Cálculo do valor total dos produtos

## Tecnologias

- Java
- Programação Orientada a Objetos
- ArrayList
- Lambda Expressions
- Streams API

## Como executar

javac *.java

java Main
